# 🚀 GitHub 上传步骤

## 第一步：在 GitHub 创建仓库

1. 打开浏览器，访问：https://github.com/new

2. 填写信息：
   - **Repository name**: `research-pipeline` 或 `a-share-research-analyzer`
   - **Description**: `智能研报分析系统 - A股券商研报自动筛选与分析`
   - **Public** or **Private**: 选择一个
   - ⚠️ **不要勾选** "Add a README file"
   - ⚠️ **不要勾选** "Add .gitignore"
   - ⚠️ **不要勾选** "Choose a license"

3. 点击绿色按钮 **"Create repository"**

---

## 第二步：复制你的仓库地址

创建后，GitHub 会显示一个页面，复制类似这样的地址：
```
https://github.com/你的真实用户名/你的真实仓库名.git
```

例如：
```
https://github.com/zhangsan/research-pipeline.git
```

---

## 第三步：在终端运行命令

```bash
cd /Users/musk2/Desktop/产业链分析/自动化分析项目-prompt/research_pipeline

# 关联你的真实仓库地址（替换成你复制的地址）
git remote add origin https://github.com/你的用户名/你的仓库名.git

# 推送代码
git push -u origin main

# 推送标签
git push --tags
```

---

## 第四步：验证

访问你的 GitHub 仓库页面，应该看到所有代码已上传。

---

## 💡 提示

- 如果推送时要求登录，使用你的 GitHub 用户名和 Personal Access Token（不是密码）
- Token 获取：https://github.com/settings/tokens
