对清单内每份报告逐一处理，严格保留输入的 report_id。

- 提炼 100–250 字核心结论。
- 找出相对历史观点真正新增的信息。
- 提取关键数据、盈利预测、目标价、评级、催化和风险，并标注 PDF 页码。
- 明确区分原文事实、机构判断和推断。
- 按项目 AGENTS.md 的七项评分标准给出分项分数及惩罚项。
- 方向只表示基本面或资产影响，不表示报告重要性。
- 内容高度重复、旧闻重述或只有估值倍数变化时应扣分。
- 输出必须符合给定 JSON Schema，不写额外解释。
